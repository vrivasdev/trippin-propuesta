Mapa por Continentes, Paquetes, Promos Flash y "Arma tu Viaje"

Diapositiva 4 de 10

🌍 1. Mapa Mundial Interactivo por Continentes y Subcontinentes

  • Selección cómoda en celular y PC: Desarrollaré el mapa agrupado por grandes regiones (Sudamérica, Caribe y Centroamérica, Norteamérica, Europa, Medio Oriente, Asia, África y Oceanía).
  • Rutas de vuelo animadas: Visualización de conexiones saliendo desde Venezuela.
  • Despliegue inmediato: Al tocar una región, muestra las tarjetas de paquetes disponibles con botón "Ver más detalles".

🎒 2. Catálogo de Paquetes de Proveedores ("Destinos Estrella")

  • Carrusel interactivo con los paquetes más vendidos de la agencia.
  • Presentación clara bajo el principio "Lo concreto vende": Días exactos de duración, Precio final "Desde $X USD", iconos de Qué incluye y fotografías reales optimizadas.
  • Ventana modal con itinerario completo, galería y botón directo de cotización.

⚡ 3. Carrusel de Promociones Flash en Portada

  • Sección destacada en la página principal para ofertas por tiempo limitado o cupos de campaña.
  • Etiquetas llamativas de porcentaje de descuento (ej. -20% OFF) y precio anterior tachado para generar urgencia de compra.
  • Activación, edición o pausa en segundos desde el Panel Administrativo.

✨ 4. Creador de Paquetes Personalizados ("Arma tu Viaje")

  • Diseñado para el viajero que desea armar una solicitud a su medida fuera del catálogo fijo.
  • Permite elegir destino abierto, combinar servicios (Vuelo + Hotel + Seguro + Traslados + Actividades), fechas tentativas, cantidad de pasajeros y método de pago preferido.

Respaldo Local en AWS

Infraestructura DevOps y Requisitos de Arranque

Configuración AWS (TEST y Producción) y Recursos que Necesito

Diapositiva 7 de 10

☁️ Mi Plan DevOps Senior para su Cuenta AWS (Desde Cero)

Como su cuenta de AWS está desde cero, configuraré dos ambientes aislados: Ambiente TEST (para pruebas) y Ambiente PRODUCCIÓN (producto final):

  • Servidor Web y Servidor de Base de Datos (MySQL): Instancias separadas para TEST y PRODUCCIÓN con copias de seguridad automáticas.
  • DNS y Balanceador de Cargas (Load Balancer): Certificados SSL renovables gratuitos, alta disponibilidad y configuración de dominios.
  • GitHub + Trello Enlazados + CI/CD: Repositorio en GitHub conectado con Trello y tubería de Integración y Despliegue Continuo (CI/CD) hacia TEST y PRODUCCIÓN.
  • Transparencia Total desde el Día 1: Tendrán acceso a todo el código de GitHub, Bases de Datos, ambientes, servidores y Trello desde el primer día.

🔑 Los 5 Recursos que Necesito de Parte de Trippin VE

Para arrancar la Fase Inicial y el Levantamiento sin demoras, necesitaré:

  • 1. Wireframes que ya tienen en sus manos: Para tomarlos como base directa en la fase de Diseño (Mockups).
  • 2. Acceso a su cuenta de AWS: Para realizar el análisis y la configuración de los ambientes TEST y PRODUCCIÓN.
  • 3. Acceso de Ambiente TEST para Zoho CRM y GoHighLevel: Para probar todo el flujo de cotizaciones sin afectar su operación real.
  • 4. Accesos API para Zoho CRM y GoHighLevel: Llaves y credenciales para conectar las solicitudes y la conciliación de ventas.
  • 5. Accesos API para las Integraciones del Buscador: Credenciales de prueba (Sandbox) y documentación de KIU GDS y Restel.
